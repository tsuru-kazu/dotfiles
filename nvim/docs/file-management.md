# ファイル管理・ナビゲーション

## nvim-tree (ファイルエクスプローラー)

### 基本操作

| キー | 動作 |
|------|------|
| `<Space>e` | ファイルツリー表示/非表示 |
| `Enter` | ファイル/フォルダを開く |
| `o` | ファイル/フォルダを開く |
| `a` | 新規ファイル/フォルダ作成 |
| `d` | ファイル/フォルダ削除 |
| `r` | ファイル/フォルダ名変更 |
| `c` | ファイル/フォルダコピー |
| `x` | ファイル/フォルダ切り取り |
| `p` | ペースト |
| `R` | ツリー更新 |
| `?` | ヘルプ表示 |

## Telescope (ファジーファインダー)

### ファイル検索

| キー | 動作 |
|------|------|
| `<Space><Space>` | ファイル検索 |
| `<Space>ff` | ファイル検索 |
| `<Space>/` | テキスト検索（grep） |
| `<Space>fb` | バッファ一覧 |
| `<Space>fr` | 最近使用したファイル |
| `<Space>fh` | ヘルプタグ検索 |
| `<Space>fc` | 設定ファイル検索 |

### Telescope内での操作

| キー | 動作 |
|------|------|
| `Ctrl+n/p` | 上下移動 |
| `Esc` | Telescopeを閉じる |
| `Ctrl+c` | Telescopeを閉じる |
| `q` | Telescopeを閉じる（ノーマルモード時） |
| `Enter` | 選択 |
| `Ctrl+x` | 水平分割で開く |
| `Ctrl+v` | 垂直分割で開く |
| `Ctrl+t` | タブで開く |

## 使い方のコツ

### 効率的なファイル移動
- `<Space><Space>` でファイル検索を多用する
- `<Space>fr` で最近使ったファイルにすぐアクセス
- プロジェクト内の移動にはTelescopeが最適
