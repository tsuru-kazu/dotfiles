# Lspsaga - 高機能LSP UI

Lspsagaは、Neovimの標準LSP機能を大幅に改善し、美しく実用的なUIを提供するプラグインです。

## 概要

Lspsagaは以下の機能を強化します：
- ホバードキュメンテーション
- コードアクション
- 診断表示
- 定義・参照の検索
- リネーム機能
- アウトライン表示

## 基本キーマッピング

### ナビゲーション

| キー | 動作 | 説明 |
|------|------|------|
| `gd` | Lspsaga: Goto Definition | 定義へ移動（プレビュー付き） |
| `gr` | Lspsaga: References | 参照をfinderで検索 |
| `gD` | Goto Declaration | 宣言へ移動（標準LSP） |
| `gI` | Goto Implementation | 実装へ移動（Telescope） |
| `gy` | Goto Type Definition | 型定義へ移動（Telescope） |

### ドキュメンテーション

| キー | 動作 | 説明 |
|------|------|------|
| `K` | Lspsaga: Hover Documentation | ホバードキュメンテーション |
| `gK` | Lspsaga: Signature Help | シグネチャヘルプ |
| `Ctrl+k` | Lspsaga: Signature Help | シグネチャヘルプ（インサートモード） |

### コードアクション・編集

| キー | 動作 | 説明 |
|------|------|------|
| `<leader>ca` | Lspsaga: Code Action | コードアクション |
| `<leader>cr` | Lspsaga: Rename | リネーム |

### 診断

| キー | 動作 | 説明 |
|------|------|------|
| `<leader>cd` | Lspsaga: Line Diagnostics | 行の診断を表示 |
| `<leader>cD` | Lspsaga: Cursor Diagnostics | カーソル位置の診断を表示 |
| `[d` | Lspsaga: Previous Diagnostic | 前の診断へ移動 |
| `]d` | Lspsaga: Next Diagnostic | 次の診断へ移動 |

### アウトライン・呼び出し階層

| キー | 動作 | 説明 |
|------|------|------|
| `<leader>o` | Lspsaga: Outline | ファイルアウトライン表示 |
| `<leader>ci` | Lspsaga: Incoming Calls | 着信呼び出し表示 |
| `<leader>co` | Lspsaga: Outgoing Calls | 発信呼び出し表示 |

## 主な機能詳細

### 1. Finder（`gr`）

参照、定義、実装を統合的に検索・表示します。

**使用方法：**
1. シンボルにカーソルを合わせて `gr` を押す
2. ファインダーウィンドウが開く
3. 結果をナビゲート：
   - `o`, `<CR>`: 開く
   - `s`: 垂直分割で開く
   - `i`: 水平分割で開く
   - `t`: 新しいタブで開く
   - `q`, `<ESC>`: 閉じる

### 2. ホバードキュメンテーション（`K`）

標準のホバー機能を美しいUIで表示します。

**特徴：**
- マークダウンレンダリング
- スクロール可能
- リンクのクリック対応
- カスタマイズ可能な外観

**操作：**
- `Ctrl+f`: 下にスクロール
- `Ctrl+b`: 上にスクロール
- `gx`: リンクを開く
- `q`: 閉じる

### 3. コードアクション（`<leader>ca`）

利用可能なコードアクションを分かりやすく表示します。

**特徴：**
- 番号付きショートカット
- プレビュー機能
- カテゴリ分け表示

**操作：**
- 数字キー: 対応するアクションを実行
- `<CR>`: 選択したアクションを実行
- `q`: キャンセル

### 4. 診断表示

エラーや警告を詳細に表示します。

**機能：**
- 行診断（`<leader>cd`）: 現在行の全診断
- カーソル診断（`<leader>cD`）: カーソル位置の診断
- 診断ナビゲーション（`[d`, `]d`）

### 5. アウトライン（`<leader>o`）

ファイル構造を階層的に表示します。

**特徴：**
- シンボルの種類別アイコン
- 階層構造表示
- 自動更新
- プレビュー機能

**操作：**
- `o`: ジャンプ
- `u`: 展開/折りたたみ
- `q`: 閉じる

### 6. リネーム（`<leader>cr`）

シンボルの一括リネームを行います。

**特徴：**
- プレビュー表示
- 確認ダイアログ
- 複数ファイル対応

**操作：**
1. 新しい名前を入力
2. `<CR>`: 実行
3. `<C-c>`: キャンセル

### 7. 呼び出し階層

関数の呼び出し関係を表示します。

**着信呼び出し（`<leader>ci`）：**
- この関数を呼び出している箇所

**発信呼び出し（`<leader>co`）：**
- この関数が呼び出している関数

## ライトバルブ機能

コードアクションが利用可能な場合、ライトバルブ（💡）が表示されます。

**設定：**
- サイン列に表示
- バーチャルテキストでも表示
- インサートモードでも動作

## ウィンドウバー

現在のシンボル階層をウィンドウ上部に表示します。

**特徴：**
- ファイル名表示
- シンボル階層表示
- カラーモード対応

## 使用例・ワークフロー

### 1. コード理解フロー

```
1. `K` でドキュメント確認
2. `gd` で定義を確認
3. `gr` で使用箇所を調査
4. `<leader>o` でファイル構造を把握
```

### 2. デバッグフロー

```
1. `<leader>cd` で診断確認
2. `[d`, `]d` で問題箇所を巡回
3. `<leader>ca` で修正アクションを適用
```

### 3. リファクタリングフロー

```
1. `<leader>cr` でリネーム
2. `<leader>ca` でリファクタリングアクション
3. `gr` で影響範囲を確認
```

## カスタマイズ

設定は `lua/plugins/lsp.lua` で行われています。

### 主要設定項目：

- **UI設定**: ボーダー、色、アイコン
- **動作設定**: タイムアウト、プレビュー行数
- **キーマッピング**: 各機能のキー設定
- **ウィンドウ設定**: 位置、サイズ、透明度

## トラブルシューティング

### よくある問題

1. **Lspsagaが動作しない**
   - LSPサーバーが正常に動作しているか確認（`:LspInfo`）
   - Treesitterが適切にインストールされているか確認

2. **アイコンが表示されない**
   - nvim-web-deviconsが正しくインストールされているか確認
   - フォントがNerd Fontかどうか確認

3. **パフォーマンスの問題**
   - `request_timeout` を調整
   - 不要な機能を無効化

### ログ確認

```vim
:LspInfo           " LSP状態確認
:checkhealth       " 全体的な健康状態
:Lspsaga --version " Lspsagaバージョン確認
```

## ヒント

- **効率的な使い方**: よく使う機能のキーマッピングを覚える

- **プレビュー**: 定義ジャンプ前にプレビューで内容確認
- **診断**: 問題のある行では自動的にライトバルブが表示される
