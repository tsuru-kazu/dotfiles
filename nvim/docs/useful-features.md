# 便利機能・ツール

## コメント (Comment.nvim)

### コメント操作

| キー | 動作 |
|------|------|
| `gcc` | 行コメント切り替え |
| `gbc` | ブロックコメント切り替え |
| `gc` (ビジュアル) | 選択範囲コメント |

### 対応言語

自動的に各言語のコメント記号を識別：
- JavaScript/TypeScript: `//` または `/* */`
- Python: `#`
- Lua: `--` または `--[[ ]]`
- HTML: `<!-- -->`

## 囲み文字操作 (mini.surround)

### 基本操作

| キー | 動作 |
|------|------|
| `gza"` | 囲み文字追加 (例: `hello` → `"hello"`) |
| `gzd"` | 囲み文字削除 (例: `"hello"` → `hello`) |
| `gzr"'` | 囲み文字変更 (例: `"hello"` → `'hello'`) |

### 使用例

```text
gza)    : hello → (hello)
gza]    : hello → [hello]
gza}    : hello → {hello}
gzat    : hello → <tag>hello</tag>
```

## 診断・トラブル (Trouble)

### 診断表示

| キー | 動作 |
|------|------|
| `<Space>xx` | ドキュメント診断表示 |
| `<Space>xX` | ワークスペース診断表示 |
| `<Space>xl` | ロケーションリスト |
| `<Space>xq` | クイックフィックスリスト |

### Trouble内での操作

- `Enter`: 問題箇所にジャンプ
- `q`: Troubleウィンドウを閉じる
- `r`: リフレッシュ

## 自動ペア (nvim-autopairs)

### 自動補完される文字

- `()` - 括弧
- `[]` - 角括弧
- `{}` - 波括弧
- `""` - ダブルクォート
- `''` - シングルクォート
- `` ` ` `` - バッククォート

### 特殊機能

- **スマート削除**: 開き括弧を削除すると対応する閉じ括弧も削除
- **言語対応**: 各言語に応じた特別なルール適用

## Illuminate (単語ハイライト)

### 自動ハイライト

カーソル下の単語と同じ単語を自動的にハイライト表示

### 移動操作

| キー | 動作 |
|------|------|
| `]]` | 次の同じ単語へ移動 |
| `[[` | 前の同じ単語へ移動 |

## Noice (通知・メッセージ改善)

### 改善された表示

- **LSPメッセージ**: より見やすいフォーマット
- **コマンドライン**: モダンなUI
- **通知**: 統合された通知システム
- **進行状況**: プロセスの進行状況を表示

## Markdown Preview

### プレビュー操作

| キー | 動作 |
|------|------|
| `<Space>mp` | Markdownプレビュー切り替え |

### コマンド

| コマンド | 動作 |
|----------|------|
| `:MarkdownPreview` | プレビュー開始 |
| `:MarkdownPreviewStop` | プレビュー停止 |
| `:MarkdownPreviewToggle` | プレビュー切り替え |

### 機能

- **リアルタイムプレビュー**: 編集と同時にブラウザで更新
- **数式サポート**: KaTeX対応
- **シーケンス図**: Mermaid対応
- **コードハイライト**: シンタックスハイライト

## 使い方のコツ

### 効率的な編集
- `gcc` でコメントの切り替えを多用
- `gza` で囲み文字を素早く追加
- Troubleで問題箇所を一覧表示して解決
- Markdownファイルはプレビューしながら編集
