# UI・ナビゲーション

## バッファ・タブ操作

### バッファ移動

| キー | 動作 |
|------|------|
| `Shift+h` | 前のバッファに移動 |
| `Shift+l` | 次のバッファに移動 |
| `[b` | 前のバッファに移動 |
| `]b` | 次のバッファに移動 |
| `<Space>bb` | 前回のバッファに戻る |
| `<Space>,` | バッファ一覧から選択 |
| `<Space>fb` | バッファ一覧から選択（Telescope） |

### バッファ管理

| キー | 動作 |
|------|------|
| `<Space>bd` | バッファ削除（ファイルを閉じる） |
| `<Space>bo` | 他のバッファを全て閉じる |
| `<Space>bp` | バッファをピン留め |
| `<Space>bP` | ピン留めしていないバッファを削除 |

## ウィンドウ操作

### エディタ分割

| コマンド | 動作 |
|----------|------|
| `:split` または `:sp` | 水平分割（上下に分割） |
| `:vsplit` または `:vsp` | 垂直分割（左右に分割） |
| `:split <ファイル名>` | 指定ファイルを水平分割で開く |
| `:vsplit <ファイル名>` | 指定ファイルを垂直分割で開く |

### ウィンドウ間の移動

| キー | 動作 |
|------|------|
| `Ctrl+h` | 左のウィンドウへ移動 |
| `Ctrl+j` | 下のウィンドウへ移動 |
| `Ctrl+k` | 上のウィンドウへ移動 |
| `Ctrl+l` | 右のウィンドウへ移動 |

### ウィンドウサイズ調整

| キー | 動作 |
|------|------|
| `Ctrl+Up` | ウィンドウの高さを増加 |
| `Ctrl+Down` | ウィンドウの高さを減少 |
| `Ctrl+Left` | ウィンドウの幅を減少 |
| `Ctrl+Right` | ウィンドウの幅を増加 |

### 分割設定

現在の設定：
- `splitbelow = true` - 水平分割時に下に新しいウィンドウを作成
- `splitright = true` - 垂直分割時に右に新しいウィンドウを作成
- `splitkeep = "screen"` - スクリーン位置を保持

## Bufferline

### タブライン操作

bufferlineプラグインにより、開いているバッファがタブとして表示されます。

- **マウス操作**: タブをクリックで切り替え
- **視覚的表示**: アクティブなバッファがハイライト
- **LSP診断**: タブにエラー・警告の数が表示

## Lualine (ステータスライン)

### 表示情報

- **左側**: モード、ブランチ名、ファイル名、診断情報
- **右側**: Git変更統計、エンコーディング、ファイル形式、ファイルタイプ、位置情報、時刻

### Git状態表示

- 🟢 **緑色**: 変更なし、クリーンな状態
- 🔴 **赤色**: 未保存の変更またはGitの変更がある状態

## Which-key

### ヘルプ表示

キーを押してしばらく待つと、利用可能なキーコンビネーションが表示されます。

- `<Space>` を押すと、スペースキーから始まるコマンド一覧が表示
- 各プレフィックスごとにグループ分けされて表示

## 使い方のコツ

### 効率的なナビゲーション
- バッファ間の移動は `Shift+h/l` を活用
- 複数ファイルを同時に見る時はウィンドウ分割を使用
- Which-keyでコマンドを覚える
