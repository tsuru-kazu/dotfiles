# 基本操作・設定

## 基本情報

- **リーダーキー**: `<Space>` (スペースキー)
- **設定場所**: `~/.config/nvim/`
- **プラグインマネージャー**: lazy.nvim

## 基本キーマップ

### ファイル操作

| キー | 動作 |
|------|------|
| `Ctrl+s` | ファイル保存 |
| `<Space>qq` | Neovim終了 |
| `jk` | インサートモードから抜ける |

### 便利なコマンド

| コマンド | 動作 |
|----------|------|
| `:e filename` | ファイルを開く |
| `:w` | ファイル保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 強制終了 |

## 検索・置換

### 基本検索

| コマンド | 動作 |
|----------|------|
| `/pattern` | 前方検索 |
| `?pattern` | 後方検索 |
| `n` | 次の検索結果 |
| `N` | 前の検索結果 |
| `*` | カーソル下の単語を前方検索 |
| `#` | カーソル下の単語を後方検索 |

### 置換

| コマンド | 動作 |
|----------|------|
| `:s/old/new/` | 現在行の最初のマッチを置換 |
| `:s/old/new/g` | 現在行の全てを置換 |
| `:%s/old/new/g` | 全体置換 |
| `:%s/old/new/gc` | 確認しながら全体置換 |

## 移動操作

### 基本移動

| キー | 動作 |
|------|------|
| `h` | 左に移動 |
| `j` | 下に移動 |
| `k` | 上に移動 |
| `l` | 右に移動 |
| `w` | 次の単語の先頭へ |
| `b` | 前の単語の先頭へ |
| `e` | 現在/次の単語の末尾へ |

### 行内移動

| キー | 動作 |
|------|------|
| `0` | 行の先頭へ |
| `^` | 行の最初の非空白文字へ |
| `$` | 行の末尾へ |
| `gg` | ファイルの先頭へ |
| `G` | ファイルの末尾へ |
| `<数字>G` | 指定行へ移動 |

## 編集操作

### 挿入・追加

| キー | 動作 |
|------|------|
| `i` | カーソル位置に挿入 |
| `I` | 行の先頭に挿入 |
| `a` | カーソルの後に挿入 |
| `A` | 行の末尾に挿入 |
| `o` | 下に新しい行を作成して挿入 |
| `O` | 上に新しい行を作成して挿入 |

### 削除

| キー | 動作 |
|------|------|
| `x` | 1文字削除 |
| `dw` | 単語削除 |
| `dd` | 行削除 |
| `D` | カーソル位置から行末まで削除 |
| `d$` | カーソル位置から行末まで削除 |
| `d0` | カーソル位置から行頭まで削除 |

### コピー・ペースト

| キー | 動作 |
|------|------|
| `yy` | 行をコピー |
| `yw` | 単語をコピー |
| `y$` | カーソル位置から行末までコピー |
| `p` | カーソル後にペースト |
| `P` | カーソル前にペースト |

### アンドゥ・リドゥ

| キー | 動作 |
|------|------|
| `u` | アンドゥ |
| `Ctrl+r` | リドゥ |

## ビジュアルモード

### モード選択

| キー | 動作 |
|------|------|
| `v` | 文字単位のビジュアルモード |
| `V` | 行単位のビジュアルモード |
| `Ctrl+v` | ブロック（矩形）ビジュアルモード |

### ビジュアルモード内操作

| キー | 動作 |
|------|------|
| `d` | 選択範囲削除 |
| `y` | 選択範囲コピー |
| `c` | 選択範囲削除して挿入モード |
| `>` | インデント追加 |
| `<` | インデント削除 |

## プラグイン管理

### Lazy.nvim

| コマンド | 動作 |
|----------|------|
| `:Lazy` | Lazy UI表示 |
| `:Lazy sync` | プラグイン同期 |
| `:Lazy update` | プラグイン更新 |
| `:Lazy clean` | 不要プラグイン削除 |
| `<Space>l` | Lazy UI表示（キーマップ） |

## トラブルシューティング

### ヘルプ・情報

| コマンド | 動作 |
|----------|------|
| `:help <topic>` | ヘルプ表示 |
| `:messages` | Neovimのメッセージ確認 |
| `:checkhealth` | 設定状態確認 |
| `:version` | Neovimバージョン確認 |

### 設定関連

| ファイル | 用途 |
|----------|------|
| `~/.config/nvim/init.lua` | メイン設定ファイル |
| `~/.config/nvim/lua/config/` | 基本設定 |
| `~/.config/nvim/lua/plugins/` | プラグイン設定 |

## 効率的な使い方のコツ

### 1. 基本操作の習得
- hjkl移動を覚える
- ビジュアルモードを活用
- 数字と組み合わせた操作（例：`5dd`で5行削除）

### 2. 検索の活用
- `/` と `n` でファイル内検索
- `*` でカーソル下の単語を検索
- 置換は段階的に（まず確認、次に全体）

### 3. 設定のカスタマイズ
- `~/.config/nvim/lua/config/` 内のファイルを編集
- `~/.config/nvim/lua/plugins/` 内でプラグイン設定をカスタマイズ
- `:checkhealth` で問題を確認
