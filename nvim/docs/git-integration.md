# Git統合

## Gitsigns

### ハンク操作

| キー | 動作 |
|------|------|
| `]h` | 次のハンクへ移動 |
| `[h` | 前のハンクへ移動 |
| `<Space>ghs` | ハンクをステージング |
| `<Space>ghr` | ハンクをリセット |
| `<Space>ghp` | ハンクプレビュー |
| `<Space>ghb` | 行をブレーム表示 |
| `<Space>ghd` | 差分表示 |

### 視覚的インジケーター

- **行番号の左側**: 変更状況を色で表示
  - 緑: 新規追加行
  - 青: 変更行
  - 赤: 削除行

## DiffView

### 基本操作

| キー | 動作 |
|------|------|
| `<Space>gd` | DiffView表示 |
| `:DiffviewOpen` | DiffView開く |
| `:DiffviewClose` | DiffView閉じる |
| `q` | DiffView閉じる |

### DiffView内での操作

| キー | 動作 |
|------|------|
| `<Tab>` | ファイル一覧とdiff表示の切り替え |
| `]c` | 次の変更箇所へ移動 |
| `[c` | 前の変更箇所へ移動 |
| `do` | 変更を取得（diff obtain） |
| `dp` | 変更を送信（diff put） |

## Git操作

### 基本コマンド

| キー | 動作 |
|------|------|
| `<Space>gc` | Gitコミット一覧 |
| `<Space>gs` | Git状態表示 |

## ステータスライン表示

ステータスラインでGitの状態が色で表示されます：

- 🟢 **緑色**: 変更なし、クリーンな状態
- 🔴 **赤色**: 未保存の変更またはGitの変更がある状態

## 使い方のコツ

### 効率的なGit作業
- `]h` / `[h` でハンク移動して変更箇所を確認
- `<Space>ghs` で部分的にステージング
- `<Space>ghp` でプレビューしてから変更を確定
- DiffViewで全体的な変更を確認

### ワークフロー例

1. ファイルを編集
2. `]h` で変更箇所を確認
3. `<Space>ghp` でプレビュー
4. `<Space>ghs` で必要な部分をステージング
5. `<Space>gd` で全体の変更を確認
6. コミット実行
