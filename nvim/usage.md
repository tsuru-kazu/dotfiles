# Neovim モダン設定 使い方ガイド

このドキュメントでは、設定されたNeovimの基本的な使い方と主要なプラグインの操作方法を説明します。

## 基本情報

- **リーダーキー**: `<Space>` (スペースキー)
- **設定場所**: `~/.config/nvim/`
- **プラグインマネージャー**: lazy.nvim

## 📁 ファイル管理・ナビゲーション

### nvim-tree (ファイルエクスプローラー)

| キー | 動作 |
|------|------|
| `<Space>e` | ファイルツリー表示/非表示 |
| `Enter` | ファイル/フォルダを開く |
| `o` | ファイル/フォルダを開く |
| `a` | 新規ファイル/フォルダ作成 |
| `d` | ファイル/フォルダ削除 |
| `r` | ファイル/フォルダ名変更 |
| `c` | ファイル/フォルダコピー |
| `x` | ファイル/フォルダ切り取り |
| `p` | ペースト |
| `R` | ツリー更新 |
| `?` | ヘルプ表示 |

### Telescope (ファジーファインダー)

| キー | 動作 |
|------|------|
| `<Space><Space>` | ファイル検索 |
| `<Space>ff` | ファイル検索 |
| `<Space>/` | テキスト検索（grep） |
| `<Space>fb` | バッファ一覧 |
| `<Space>fr` | 最近使用したファイル |
| `<Space>fh` | ヘルプタグ検索 |
| `<Space>fc` | 設定ファイル検索 |

**Telescope内での操作:**
| キー | 動作 |
|------|------|
| `Ctrl+n/p` | 上下移動 |
| `Esc` | Telescopeを閉じる |
| `Ctrl+c` | Telescopeを閉じる |
| `q` | Telescopeを閉じる（ノーマルモード時） |
| `Enter` | 選択 |
| `Ctrl+x` | 水平分割で開く |
| `Ctrl+v` | 垂直分割で開く |
| `Ctrl+t` | タブで開く |

## 🚀 効率的な使い方のコツ

### 1. ファイル移動
- `<Space><Space>` でファイル検索を多用する
- `<Space>fr` で最近使ったファイルにすぐアクセス

### 2. コード編集
- `gd` で定義ジャンプを活用
- `<Space>ca` でコードアクションを使う
- LSPの補完機能を最大限活用

### 3. Git作業
- `]h` / `[h` でハンク移動
- `<Space>ghs` で部分的にステージング

### 4. 設定のカスタマイズ
- `~/.config/nvim/lua/config/` 内のファイルを編集
- `~/.config/nvim/lua/plugins/` 内でプラグイン設定をカスタマイズ

## 🆘 トラブルシューティング

### よくある問題

1. **LSPが動かない**: `:Mason` でLSPサーバーがインストールされているか確認
2. **補完が出ない**: `:LspInfo` でLSPが起動しているか確認
3. **テーマが表示されない**: `:Lazy sync` でプラグインを同期

### ログ確認

```vim
:messages        " Neovimのメッセージ確認
:LspInfo        " LSP状態確認
:checkhealth    " 設定状態確認
```
