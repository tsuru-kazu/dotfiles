# このプロジェクトでのNeovimの基本的な使い方

## 概要

このプロジェクトのNeovim設定は**AstroNvim v5**をベースにしており、モダンなプラグインとカスタムキーマッピングが設定されています。

---

## 基本情報

- **ベース**: AstroNvim v5
- **プラグイン管理**: lazy.nvim
- **テーマ**: GitHub Dark (透過設定有効)
- **Leaderキー**: `Space`

## 📁 ファイルエクスプローラー (oil.nvim)

oil.nvimは、**ディレクトリをバッファとして編集する**というユニークなアプローチのファイルエクスプローラーです。
通常のテキスト編集と同じ感覚でファイル操作ができます。

### 基本操作

| キー | 説明 |
|------|------|
| `<Leader>e` | oil.nvimでカレントディレクトリを開く |
| `-` | 親ディレクトリを開く（vim-vinegarスタイル） |
| `<CR>` | ファイル/ディレクトリを開く |
| `<C-s>` | 垂直分割で開く |
| `<C-h>` | 水平分割で開く |
| `<C-t>` | タブで開く |
| `<C-p>` | プレビュー |
| `<C-c>` | 閉じる |
| `<C-l>` | リフレッシュ |

### ファイル操作（バッファ編集と同じ）

oil.nvimの最大の特徴は、**Vimの通常の編集操作でファイルを操作できる**ことです。

| キー | 説明 |
|------|------|
| `dd` | ファイル/ディレクトリを削除 |
| `yy` | ファイル/ディレクトリをコピー |
| `p` | ペースト（移動/コピー） |
| `cw` | ファイル名を変更 |
| `i` | 新しいファイル名を入力して作成 |
| `o` | 下に新しい行を追加してファイル作成 |
| `:w` | 変更を保存（実際のファイルシステムに反映） |

**例**: ファイルをリネーム
1. ファイル名の上で`cw`を押す
2. 新しい名前を入力
3. `:w`で保存

**例**: 複数ファイルを削除
1. ビジュアルモード（`V`）で複数行選択
2. `d`で削除
3. `:w`で保存

### 表示・ナビゲーション

| キー | 説明 |
|------|------|
| `g.` | 隠しファイルの表示/非表示をトグル |
| `gs` | ソート方法を変更 |
| `gx` | 外部アプリケーションで開く |
| `g?` | ヘルプを表示 |
| `_` | カレントワーキングディレクトリを開く |
| `` ` `` | Vimのカレントディレクトリを変更 |
| `~` | タブローカルのカレントディレクトリを変更 |

### 便利な使い方

**ディレクトリ作成**:
ファイル名の末尾に`/`をつけると、ディレクトリとして作成されます。
```
o を押して "new-folder/" と入力 → :w で保存
```

**複数ファイルの一括操作**:
1. ビジュアルモードで複数ファイルを選択
2. `y`でヤンク
3. 別のディレクトリに移動
4. `p`でペースト
5. `:w`で保存

**注意**: このプロジェクトでは隠しファイルがデフォルトで表示される設定になっています。

## 🎨 便利なプラグイン

### Noice.nvim (コマンドラインUI改善)
`:` を入力すると、モダンなポップアップが表示されます。

### LSP Signature
関数のシグネチャがリアルタイムで表示されます。

### Which-Key
キーマッピングを途中まで入力すると、利用可能なキーのリストが表示されます。

### Render Markdown
Markdownファイルを見やすく表示します。

### Discord Presence
Discord Rich Presenceで編集中のファイルを表示します。

### Todo Comments
`TODO:`, `FIXME:`, `NOTE:` などのコメントをハイライト表示します。

## 🚀 ヒント

1. **コマンドパレット**: `<Leader>fc` で利用可能なコマンドを検索できます
2. **ヘルプ**: `:help <keyword>` でドキュメントを参照できます
3. **AstroNvimドキュメント**: `:h astro` で詳細なヘルプが見られます
4. **キーバインディング**: `<Leader>` を押すとWhich-Keyが利用可能なキーを表示します
